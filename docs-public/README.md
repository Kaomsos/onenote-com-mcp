# Public Documentation

**English** | [简体中文](README.zh-CN.md)

This directory holds the public-facing documentation for Local OneNote MCP, in two parallel language trees. The English tree is the authoritative public version; the Chinese tree is a synchronized mirror. Both trees must be updated in the same change.

For contract-level detail (exact tool parameters, response schemas, architecture), these guides link into the maintainer-facing docs under [`docs/`](../docs/README.md), which remain the authoritative source.
